# The Green Locker

Premium green, black, and gold brand website.

This repository contains the source for the pre-launch marketing site. **It is not a live cannabis store**: no checkout, product orders, shipping, or verified age-gating are enabled.

## Status
- Site: static HTML/CSS/JavaScript marketing prototype.
- Production deployment: **not configured**. Netlify will be connected separately when requested.
- Brand logo: the exact approved circular gold-and-green artwork is maintained in the downloadable brand kit; website assets are being prepared for this repository.
- Domain: TheGreenLocker.com (ownership and DNS not verified).
- Legal: Commerce, advertising, age verification, and fulfillment depend on applicable licensing and jurisdiction; no nationwide marijuana shipping is asserted.

## Development workflow
Site development happens in pull requests; keep `main` as the integration branch. The static site can be previewed with any local HTTP server.

## Brand
- Deep forest: `#092A1C`
- Near-black: `#07110D`
- Metallic gold: `#DAB46E`
- Warm cream: `#F4F0E5`

See the original [brand assets and standalone prototype](https://chatgpt.com/) from the project conversation; those assets are separate from this Git repository until committed.

## Future Netlify deployment
Connect this GitHub repository to Netlify only after design review, required asset upload, trademark/legal checks, and launch approval. Publish directory is the repository root for this static site; build command is not needed.
